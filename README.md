# 汤姆猫跑酷（3D 像素风）

原生 Android 3D 无尽跑酷小游戏，类似《汤姆猫金币跑》的核心玩法。
纯 Kotlin + OpenGL ES 2.0 实现，无任何第三方依赖，像素/体素方块风格。

## 玩法

- 猫在三条跑道上自动向前跑，速度越来越快
- **左右滑动**：换道
- **上滑 / 点击**：跳跃（跳过矮栏）
- **下滑**：铲滑（滑过高空横杆）
- 大木箱只能换道躲开；吃金币加分（1 金币 = 10 分）
- **施工跳台**：两条跑道会被木箱封住，需提前切到黄色斜坡所在跑道，
  沿坡冲上去越过水泥路障，并收集坡面金币
- **连击**：连续吃金币（1.6 秒内续接）可提升得分倍率，每 5 枚升一级，最高 x5；
  超时或受击重置。倍率只加分，不虚增金币数量
- 撞上障碍游戏结束，最高分自动保存

## 道具与索道

- **磁铁**（红色 U 形，基础 8 秒，可叠加至 16 秒）：自动吸附附近各条道上的金币
- **头盔**（黄色安全帽，最多 2 层）：每层抗一次撞击
- **加倍**（紫色宝石，基础 10 秒，可叠加至 20 秒）：金币与里程得分翻倍
- **闪电冲刺**（青色闪电，基础 6 秒，可叠加至 12 秒）：速度 +30%，
  撞击免疫并撞碎障碍（+25 分），带青色尾迹
- **高空索道**：随机出现、长度随机（30~80 米）。在地面对准
  绿色入口门架所在的跑道即可自动抓上索道，滑行期间免疫一切障碍，
  钢缆下还挂着一排金币；到出口自动落下，左右滑/下滑可提前下索道
- 左上角 HUD 实时显示生效中的道具和滑索状态

## 局内任务与成就

每局三项任务（完成即得分奖励，只结算一次）：

| 任务 | 目标 | 奖励 |
|------|------|------|
| 金币 | 收集 50 | +200 |
| 连击 | 本局最高连击 15 | +250 |
| 距离 | 奔跑 800 米 | +300 |

持久成就（SharedPreferences 保存，共 4 个）：

- 金币收藏家：累计 500 金币
- 长跑健将：累计 5000 米
- 任务达人：累计完成 10 次局内任务
- 连击大师：历史最高连击 25

## 反馈与打磨

- **音效**：跳跃、铲滑、金币、道具、头盔碎裂、撞击、上索道、破纪录、
  连击升级、冲刺、撞碎、任务、成就，全部为启动时代码合成的 PCM 波形
- **振动**：金币/跳跃轻触，道具/连击中等，撞击/死亡强反馈
- **飘分**：吃金币、撞碎、任务完成时屏幕中央弹出分数文字
- **粒子**：拾取与撞碎时喷出体素碎片
- **速度感**：高速时动态 FOV 加宽、道路速度线；冲刺时强化尾迹
- **镜头震动**：受击时短促衰减震动
- **跑酷中破纪录**：金色「新纪录！」横幅 + 号角音
- **猫咪颜色**：开始/结束界面可在 蓝灰/橘黄/乌黑/粉红 四色间循环

## 画面

体素方块世界：方块猫、方块树、方块云、旋转金币块、远山台地，8-bit 配色。
天气（晴/雨/雪）与**昼夜循环**独立叠加：黄昏暖色、夜晚月亮星星与路灯，
保持跑道可读性。渲染上有 4x MSAA、半球环境光 + 方向光、距离雾、软阴影。

## 构建与运行

需要 Android SDK（`local.properties` 里指向本机 SDK 路径）和 JDK 17+：

```bash
JAVA_HOME="/Applications/Android Studio.app/Contents/jbr/Contents/Home" ./gradlew assembleDebug
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

也可以直接用 Android Studio 打开本目录运行。最低支持 Android 7.0（API 24）。

## 代码结构

- [Game.kt](app/src/main/java/com/vvenv/tomrun/Game.kt) — 游戏逻辑：物理、障碍生成、连击/冲刺/任务/成就、计分
- [GameRenderer.kt](app/src/main/java/com/vvenv/tomrun/GameRenderer.kt) — OpenGL ES 体素渲染：相机、天气昼夜、粒子、速度线
- [Mesh.kt](app/src/main/java/com/vvenv/tomrun/Mesh.kt) — 立方体网格
- [HudView.kt](app/src/main/java/com/vvenv/tomrun/HudView.kt) — 中文像素 HUD、飘分、任务进度、滑动手势
- [SoundFx.kt](app/src/main/java/com/vvenv/tomrun/SoundFx.kt) — 程序化音效
- [MainActivity.kt](app/src/main/java/com/vvenv/tomrun/MainActivity.kt) — 入口，GLSurfaceView + HUD + 振动
