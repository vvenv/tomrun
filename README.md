# 汤姆猫跑酷（3D 像素风）

原生 Android 3D 无尽跑酷小游戏，类似《汤姆猫金币跑》的核心玩法。
纯 Kotlin + OpenGL ES 2.0 实现，无任何第三方依赖，像素/体素方块风格。

## 玩法

- 猫在三条跑道上自动向前跑；速度从 12 平滑爬升，约 70 秒接近上限 28
- **左右滑动**：换道
- **上滑 / 点击**：跳跃（跳过矮栏）
- **下滑**：铲滑（滑过高空横杆）
- 大木箱只能换道躲开；吃金币加分（1 金币 = 10 分）
- **施工跳台**：约 450 米后出现；两条道被木箱封住，需提前切到黄色斜坡
- **连击**：1.6 秒内连续吃金币；阈值 5 / 12 / 22 / 35 对应 x2~x5；
  倍率只加分，不虚增金币与钱包；超时或受击重置
- 障碍间距按反应时间缩放（约 1.7s → 0.95s），道具约每 7 波保底一次
- **金币不贴障碍**：吃金币时视线锁在金币上，所以金币串的**头尾**都与同道障碍
  保持约 0.6 秒的间距（10~18 个单位）——
  波间距会为本波金币串的长度自动加长，横杆的同道金币串退到横杆之后起排。
  实测同道「金币串 → 障碍」最小间距从 0 提升到 10，代价只是障碍与金币各少约 5%
- 撞上障碍游戏结束，最高分与统计自动保存

## 平行宇宙传送门

- 约 320 米后出现**旋转彩环传送门**（横跨三条跑道），之后每 480~740 米一扇；
  穿过即随机穿越到另一个平行宇宙，切换伴随白闪、横幅、专属音效与重震
- 六大宇宙各有专属配色、景物、环境粒子与物理/福利：

| 宇宙 | 专属景观 | 物理 / 福利 |
|------|---------|------------|
| 草原世界 | 树木花草 + 天气/昼夜 | 基准 |
| 水下世界 | 摇摆海草 · 珊瑚 · 头顶游鱼 · 气泡 | 重力 0.45x 漂浮跳 |
| 天空世界 | 漂浮岛 · 彩虹拱桥 · 飞鸟 | 跳得更高 |
| 熔岩世界 | 黑曜石 · 发光岩浆池 · 火山 · 火星 | 金币分数 x2 |
| 糖果世界 | 棒棒糖树 · 软糖丛 · 拐杖糖 · 糖屑 | 钱包金币 x2 |
| 星空世界 | 环状行星 · 陨石 · 霓虹水晶 · 星尘 | 超低重力 |

- 传送门门芯颜色预告目标宇宙；局内任务新增「穿越传送门」
- 主菜单显示**宇宙图鉴**（已探索 x/6）与累计穿越次数，均持久保存
- **集齐六大宇宙**：一次性大奖 1000 钱包金币，横幅 + 彩色礼花 + 号角庆祝，
  即时落盘不丢失；集齐后主菜单图鉴行变为金色「全收集！」

## 文物博物馆（寓教于乐）

- 跑道上稀有刷出**中国文物**（首件约 180 米，之后每 280~520 米一件），
  发光小鼎造型 + 头顶名牌与配图，吃金币的方式收集
- 共 **32 件文物**，按稀有度分三档：普通（青铜绿）/ 稀有（青玉蓝）/ 传说（鎏金），
  传说文物 600 米后才会出现；未收集的文物优先刷出，方便集齐图鉴
- 选材贴合中小学历史课本：甲骨文、后母戊鼎、越王勾践剑、曾侯乙编钟、
  兵马俑、清明上河图、敦煌飞天、三星堆面具、长信宫灯……每件配朝代、
  一句小知识与**专属像素配图**
- 拾取时横幅展示「发现文物 + 朝代」，随后单独一行给出小知识，
  并按稀有度奖励分数与钱包金币（+100/5 · +250/15 · +500/40）；
  局内任务含「发现文物」
- 文物头顶名牌**只在临近时淡入**（约身前 15~38 个单位）：名牌画在远处路面位置，
  原来 100 个单位外就糊出来，会挡住后面好几波障碍；远处只留 3D 模型自身发光提示
- 家中「**藏品**」翻页浏览图鉴：已收集的显示配图、朝代与小知识可反复阅读，
  未收集的显示「？？？」剪影；**集齐 32 件**一次性大奖 2200 钱包金币，永久保存

### 润物细无声

知识只在孩子**自己挖到之后**才反复出现，全程不弹题、不考问：

- 拾取横幅不带「小知识」这类说教前缀，写法像博物馆展签；
  拾取瞬间本就会减速，停留时间放宽到 5.5 秒，刚好够读完一句
- 主菜单与结算页空白处安静轮播一条**已收集**文物的展签
  （名称 · 朝代 + 一句小知识，每 7 秒一换，淡入淡出）；
  一件都没收集时什么都不显示，不做任何催促

- 浏览「房屋 / 屋顶」标签时场景即时预览；未购装饰以半透明幽灵预览摆放位置

  （Lv1 磁铁 5s / Lv2 +头盔 / Lv3 +加倍 5s），装扮反哺跑酷

## 道具与索道

- **磁铁**（8s，可叠至 16s）：吸附身前 14 个单位内的金币（跨车道，不看左右距离）。
  参照物：跑道左右总宽只有 4.4，波间距 18~58 —— 范围再大就会一次吸空整整一波，
  吃磁铁的几秒里走位完全不重要，三条道的金币同时朝屏幕中间飞也最闹眼睛
- **头盔**（最多 2 层）：每层抗一次撞击
- **加倍**（10s，可叠至 20s）：本局计分金币与里程翻倍（不刷钱包）
- **闪电冲刺**（6s，可叠至 12s）：速度 +25%，撞碎障碍（+25 分）
- **高空索道**：约 400 米后出现；对准绿色门架自动上索，免疫障碍

## 局内任务

每局随机抽取 3 个不重复任务（金币 / 距离 / 连击 / 跳跃 / 铲滑 / 撞碎），
目标与奖励按累计里程分新手 / 熟练 / 高手三档。
完成同时获得本局分数与**钱包金币**。

## 外观商店

跑酷中拾取金币与完成任务/成就会存入**钱包**（与本局计分金币分离）。
开始/结束界面进入「商店」，四个标签页 + **大号像素猫实时试穿预览**：

| 类别 | 项目（价格） |
|------|-------------|
| 配色 | 蓝灰 免费 / 橘黄 300 / 乌黑 800 / 粉红 1500 |
| 双脚光迹 | 无 免费 / 青色 500 / 金色 1200 / 彩虹 2500 |
| 围巾 | 无 免费 / 火红 400 / 天青 1000 / 星紫 2200 |
| 帽子 | 无 免费 / 红棒球帽 600 / 青草帽 1500 / 金皇冠 2800 |

- 双脚光迹会沿猫跑动、换道与跳跃的路线弯曲，并逐渐淡出

- 装备状态与钱包余额持久保存

## 暂停

- 跑酷中点击**左上角暂停按钮**：世界完全冻结，可选「继续跑酷」或
  「结束本局」（正常结算钱包与统计，不算撞车）
- 切到后台自动暂停，回来时停在暂停菜单，不会白白撞死

## 反馈与画面

- 程序化音效、分级振动、飘分、粒子、动态 FOV、速度线、镜头震动
- 天气（晴/雨/雪）与昼夜循环独立叠加；夜晚有月亮、星星与路灯
- HUD 使用 [Fusion Pixel](https://github.com/TakWolf/fusion-pixel-font) 12px 简体像素字体（OFL），字号取 12 的整数倍

## 护眼调色

面向中小学玩家，画面要能长时间看而不累。
[EyeComfort.kt](app/src/main/java/com/vvenv/tomrun/EyeComfort.kt) 用**一条公式**统一分级：

1. **降饱和**（0.74）——把霓虹拉回写实像素的泥土 / 草木 / 石灰调，画面不再「花」
2. **抬黑压白**（0.07 ~ 0.90）——最暗不到纯黑、最亮不到纯白，去掉刺眼的极端对比
3. **轻微暖偏**（蓝通道 ×0.94）——削一点蓝光，整体偏暖更耐看

三条出图路径都走它，赛道 / HUD / 藏品图观感一致：

| 路径 | 接入点 |
|------|--------|
| 3D 世界 | `GameRenderer.emit` / 天空 clearColor / 雾色 |
| HUD | `HudView.EyeSafePaint` 覆盖 `setColor` |
| 藏品位图 | `RelicIcons.blitPaint` 挂 `ColorMatrixColorFilter` |

各处元素原有的色相与明暗关系（如「铜褐避开草绿」）都是手工调过的，
所以只做统一分级，**不改单个色值常量**；想整体加减刺激度，改 `EyeComfort` 里那四个数即可。

同时削弱了高频刺激源：

- 镜头震动幅度降到约四成（晕眩感的主要来源）
- 穿越白闪由 120 alpha 纯白改为 46 alpha 暖白，只提示换场景，不爆闪
- 速度线强度减半，只在冲刺时才明显

> ⚠️ 分级的副作用：**又淡又亮**的颜色降饱和后会糊成一块，读不出原意。
> 闪电冲刺道具原本用亮青 (0.25,0.90,1.0)，分级后成了 #62C6CA，和亮核明度接近，
> 整个看着像块「冻住的冰」。改成深蓝身 (0.12,0.62,1.0) + 烧白芯，靠**高反差**读出电弧。
> 以后加自发光道具，记得让本体压得比芯暗、比芯饱和。

## 构建与运行

```bash
JAVA_HOME="/Applications/Android Studio.app/Contents/jbr/Contents/Home" ./gradlew assembleDebug
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

最低支持 Android 7.0（API 24）。

## 代码结构

- [Game.kt](app/src/main/java/com/vvenv/tomrun/Game.kt) — 数值节奏、任务、成就、钱包商店、物理与生成
- [GameRenderer.kt](app/src/main/java/com/vvenv/tomrun/GameRenderer.kt) — OpenGL 体素渲染与双脚光迹
- [HudView.kt](app/src/main/java/com/vvenv/tomrun/HudView.kt) — HUD、商店/成就面板、手势
- [EyeComfort.kt](app/src/main/java/com/vvenv/tomrun/EyeComfort.kt) — 全局护眼调色（唯一色彩分级公式）
- [RelicIcons.kt](app/src/main/java/com/vvenv/tomrun/RelicIcons.kt) — 藏品像素配图
- [StargazeCards.kt](app/src/main/java/com/vvenv/tomrun/StargazeCards.kt) — 望月镜观测卡
- [assets/fonts/](app/src/main/assets/fonts/) — Fusion Pixel 12px（zh_hans）
- [SoundFx.kt](app/src/main/java/com/vvenv/tomrun/SoundFx.kt) — 程序化音效
- [MainActivity.kt](app/src/main/java/com/vvenv/tomrun/MainActivity.kt) — 入口与振动
